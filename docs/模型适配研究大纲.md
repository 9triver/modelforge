# 模型适配技术研究大纲

面向团队内部的技术报告，梳理我们要研究什么、怎么研究、用什么工具。与[模型适配实践计划](模型适配实践计划.md)配套使用。

---

## 1. 我们要解决什么问题

模型训练时的数据分布和部署时不一样，性能会退化。我们要搞清楚三件事：

1. **怎么发现**分布偏移了（Detection）
2. **怎么修**模型让它在新分布上也能用（Adaptation）
3. **怎么判断**修没修好（Evaluation）

核心分析框架：**漂移类型 × 模型族 → 适配策略**

---

## 2. 分布偏移的分类

| 类型 | 什么变了 | 什么没变 | 直觉理解 |
|-----|---------|---------|---------|
| Covariate Shift | P(X) | P(Y\|X) | 输入数据的分布变了，但规律没变 |
| Label Shift | P(Y) | P(X\|Y) | 类别比例变了 |
| Concept Drift | P(Y\|X) | — | 同样的输入，该给的答案变了 |
| Domain Shift | P(X,Y) 整体 | — | 换了一个完全不同的环境 |

理论支撑：Ben-David 域适配误差上界 ε_T ≤ ε_S + d_H(S,T) + λ*，即目标域误差由源域误差、域间距离、最优联合误差三项决定。

## 4. 适配方法体系

按干预层次从轻到重排列：

### 4.1 输出层：概率校准（最轻量）

改的不是模型，是输出的概率值。

| 方法 | 原理 | 参数量 | 实现 |
|-----|------|-------|------|
| Platt Scaling | 对 logits 拟合 Sigmoid | 2 | `sklearn.calibration.CalibratedClassifierCV(method='sigmoid')` |
| Isotonic Regression | 非参数单调拟合 | O(n) | 同上 `method='isotonic'` |
| Temperature Scaling | logits / T | 1 | 自实现 ~30行 |

**各模型的校准特性**（决定了要不要做、用哪种）：

| 模型 | 原始校准 | 校准后提升 | 推荐方法 |
|-----|---------|----------|---------|
| LR | 好 | 低 | 通常不需要 |
| NB | 差(过度自信) | 高 | Isotonic |
| RF | 中 | 中 | Platt |
| XGBoost | 中 | 中 | Platt |
| SVM | Platt即原生 | — | — |
| ResNet/ViT | 差(过度自信) | 高 | Temperature |

**关键判断**：很多看似需要域适配的场景，仅做校准就能恢复可用性能。**校准应作为适配的第一步，不是最后一步。**

### 4.2 数据层：实例加权

不改模型结构，通过给训练样本加权来修正分布偏移。

| 方法 | 原理 | 实现 |
|-----|------|------|
| uLSIF | 最小二乘密度比估计 P_T(x)/P_S(x) | `pip install densratio` |

适用于所有支持 `sample_weight` 的模型（sklearn/xgboost 原生支持）。本研究选 uLSIF 作为代表，因为它在三种主流密度比估计（KMM/KLIEP/uLSIF）中实现最简单、数值最稳定。

### 4.3 特征层：分布对齐

在特征空间里对齐源域和目标域的分布。

**传统方法（表格数据）**

| 方法 | 原理 | 实现 |
|-----|------|------|
| TCA | RKHS 中边缘分布对齐 | `transfertools` 包或自实现 ~100行 |

**深度方法（图像数据）**

| 方法 | 原理 | 实现 |
|-----|------|------|
| DANN | 域判别器 + 梯度反转层 | [thuml/Transfer-Learning-Library](https://github.com/thuml/Transfer-Learning-Library) (`tllib`) |
| SHOT | 信息最大化 + 伪标签(Source-Free) | 同上 `tllib`，或[原作者代码](https://github.com/tim-learn/SHOT) |
| AdaBN | 只替换 BN 层的 running mean/var | 自实现 ~20行 |

**AdaBN 特别说明**：零训练成本，只需在目标域数据上跑一遍前向传播更新 BN 统计量。仅适用于含 BN 的 CNN（ResNet 等），ViT 用 LayerNorm 不适用。在轻度 Domain Shift 下效果显著，是最该先试的深度适配方法。

### 4.4 模型层：改模型参数

**传统ML**

| 模型 | 轻量适配 | 重度适配 |
|-----|---------|---------|
| RF | 加新树 | 全量重训(分钟级) |
| XGBoost | `xgb_model` 参数续训 | 全量重训 |
| LR | SGD 增量更新 | 全量重训(极低成本) |
| SVM(RBF) | 不支持增量 | 全量重训(成本高) |

**深度学习**

| 方法 | 改了什么 | 参数效率 | 实现 |
|-----|---------|---------|------|
| 全量微调 | 所有参数 | 低 | PyTorch 原生 |
| 线性探测 | 只训末层 | 极高 | 冻结 backbone，训最后一层 |
| LoRA | 低秩矩阵插入 | 高(<1%参数) | `pip install peft` (HF PEFT) |
| CoOp | 学习文本 prompt | 极高 | [KaiyangZhou/CoOp](https://github.com/KaiyangZhou/CoOp) |

**参数高效方法（LoRA/CoOp）正在成为 Transformer/ViT 上的默认适配手段**，逐步取代全量微调和域对抗方法。

### 4.5 方法选择决策表

给定漂移类型和模型，优先试什么：

| 漂移类型 | 表格模型(LR/RF/XGB) | CNN(ResNet) | ViT/CLIP |
|---------|-------------------|-------------|----------|
| Covariate Shift (轻度) | 校准 | AdaBN | 线性探测 |
| Covariate Shift (重度) | uLSIF加权 / 重训 | DANN | LoRA |
| Label Shift | 重校准(Platt) | Temperature Scaling | Temperature Scaling |
| Concept Drift | 续训 / 滑动窗口重训 | 微调 | LoRA微调 |
| Domain Shift | TCA + 重训 | DANN / SHOT | CoOp / LoRA |

**优先级原则**：校准 → 加权 → 增量/续训 → 域对抗/LoRA → 全量重训。从轻到重试，够用就停。

### 4.6 成本-效果定位

```
高效果 ▲
       │          · LoRA        · 全量微调(DL)
       │        · DANN/SHOT
       │     · AdaBN
       │   · TCA
       │  · uLSIF加权
       │ · Platt校准
       │· XGBoost续训
       └──────────────────────────────► 高成本
     低成本
```

## 5. 检测方法体系

### 5.1 统计检验（模型无关）

| 方法 | 检测什么 | 实现 |
|-----|---------|------|
| PSI | 特征分布变化(分箱) | 自实现 ~30行 |
| KS Test | 单变量连续分布差异 | `scipy.stats.ks_2samp` |
| MMD | 高维分布差异 | 自实现(高斯核) ~50行 |
| 域分类器 | 整体域差异 | 训练一个简单分类器区分源/目标，看 AUC |

### 5.2 模型内部信号（模型相关）

| 模型 | 可监控信号 | 怎么提取 |
|-----|-----------|---------|
| RF | OOB error 突增 | `oob_score_` 属性 |
| XGBoost | SHAP 值分布变化 | `shap` 库 |
| LR | 系数稳定性 | 对比不同时期训练的 `coef_` |
| ResNet | BN 层统计量偏移 | 遍历 BN 层，比较 `running_mean/var` |
| ViT | CLS token embedding 漂移 | hook 提取 → 计算 MMD |
| ViT | Attention 熵变化 | hook 提取 attention weights → 计算熵 |

### 5.3 Concept Drift 检测（流式场景）

| 方法 | 特点 | 实现 |
|-----|------|------|
| ADWIN | 自适应窗口，最实用 | `river` 库: `river.drift.ADWIN` |
| DDM | 简单，只能检测突变 | `river.drift.DDM` |

### 5.4 诊断决策流程

```
新数据到达
    │
    ├─ 特征分布检验 (PSI/KS)
    │   ├─ 显著偏移 → Covariate Shift
    │   └─ 不显著 ↓
    │
    ├─ 标签分布检验 (Chi-Square)
    │   ├─ 显著偏移 → Label Shift
    │   └─ 不显著 ↓
    │
    └─ 模型性能监控
        ├─ 性能下降 → Concept Drift
        └─ 性能稳定 → 无需适配
```

## 6. 评估体系

### 6.1 我们关心的指标

| 维度 | 指标 | 回答什么问题 |
|-----|------|------------|
| 判别性能 | Accuracy / F1 / AUC | 适配后预测对不对 |
| 校准性能 | ECE / Brier Score | 适配后概率准不准 |
| 检测性能 | mAP@50 | 框找得准不准(YOLO) |
| 分割性能 | mIoU | 像素分得对不对(DeepLab) |
| 适配成本 | wall-clock time / 参数比例 | 值不值得做 |
| 域距离 | Proxy A-distance | 域对齐了没有 |

### 6.2 可视化

| 图 | 说明 |
|---|------|
| Reliability Diagram | 校准曲线 vs 对角线，直观看校准效果 |
| 热力图 | 模型(行) × 方法(列)，颜色=性能提升幅度 |
| Pareto 图 | 横轴适配成本，纵轴性能提升，看哪些方法性价比高 |
| 漂移强度-性能曲线 | 横轴漂移强度，纵轴性能，看各方法在什么漂移下失效 |
| t-SNE | 源域/目标域特征分布，适配前后对比 |

### 6.3 无标签场景评估

目标域没有标注时怎么判断适配效果：

- **预测置信度分布**：适配后置信度应该回归合理区间（不过度集中于0或1）
- **多增强一致性**：同一样本多次增强推理，预测应该一致
- **邻域一致性**：特征空间中近邻的预测应该一致

## 7. 核心结论（预期验证）

以下是我们预期通过实验验证的判断：

1. **"先校准再看"**：校准是最被低估的适配手段，应该作为第一步
2. **传统ML适配的高性价比**：树模型续训+校准的组合，在 Covariate Shift 下可能比深度DA方法性价比更高
3. **AdaBN 是 CNN 适配的必测 baseline**：零成本，效果经常被高估了的复杂方法只是略好
4. **LoRA 正在统一 Transformer 的适配**：参数效率高、效果接近全量微调
5. **CLIP zero-shot 在某些场景可以直接替代传统DA**：不需要任何适配

## 8. 待研究的问题

按优先级排列：

| 优先级 | 问题 | 为什么重要 |
|-------|------|-----------|
| P0 | 给定漂移类型和模型，能否自动推荐适配策略？ | 这是研究的核心交付物 |
| P0 | 校准到底能覆盖多少比例的"需要适配"的场景？ | 决定工程中的默认策略 |
| P1 | 漂移强度到什么程度，轻量适配就不够用了？ | 给出"何时升级策略"的阈值 |
| P1 | Source-Free 方法(SHOT)的实际可用性如何？ | 隐私约束下的关键方法 |
| P2 | Foundation Model(CLIP)是否改变了适配的基本假设？ | 判断传统DA方法是否还有研究价值 |
| P2 | 适配过程是否引入安全风险（后门/对抗）？ | 安全边界 |
